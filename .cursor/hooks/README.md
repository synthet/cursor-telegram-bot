# Hook policy assets (documentation)

This folder is **not** runtime Cursor hook configuration.

| Location | Purpose |
|----------|---------|
| `.cursor/hooks/` | Policy reference and example payloads for AI agents and reviewers |
| `packages/hooks/` | Runtime hook scripts installed into the workspace (when implemented) |
| User/workspace Cursor hooks config | Generated by extension command “Install Cursor Hooks” |

See [docs/ai-workflow/hook-policy-guide.md](../docs/ai-workflow/hook-policy-guide.md).
